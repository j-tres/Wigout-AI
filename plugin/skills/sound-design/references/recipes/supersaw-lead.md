# Supersaw Lead

**Use:** big trance/EDM lead or anthemic chord stab — a wall of detuned saws that fills the stereo field and sits on top of a drop.

**Start from:** [Polysynth](../devices/polysynth.md) or [Polymer](../devices/polymer.md) with a saw source and **unison** (many stacked, detuned voices). See the guides for the unison/detune controls.

**Build:**
1. Saw oscillator with unison up — as many voices as the engine allows, spread by detune. The count and detune spread together make the "super" in supersaw: more voices = thicker, more detune = wider and more shimmering (too much = out of tune).
2. Filter to low-pass, opened fairly bright so the top saws sing; a little resonance for presence. This is a *forward* sound, not a dark one.
3. Amp envelope: for a sustained lead, fast attack + high sustain + medium release; for a stab, fast attack + short decay + low sustain.
4. Optional slow LFO to filter cutoff or to detune for gentle life on long notes (see [../../../coach/references/modulators.md](../../../coach/references/modulators.md)).
5. Chain: EQ+ (high-pass out low mud so the stack doesn't clash with bass — a supersaw does not need lows; carve ~150-250 Hz down) → Saturator (optional light drive for edge) → Reverb (hall/plate for the anthemic size) and/or synced Delay+. Width is already inherent from unison; add Chorus+ only if you want even more. See [../fx-character.md](../fx-character.md).

**Parameter targets:** Unison voices high, detune moderate (~15-40% of the control's range — wide enough to shimmer, not so wide it detunes). Filter low-pass ~55-75%, resonance low-modest. High-pass ~150-250 Hz. Reverb mix modest, longer tail.

**Variations:** brighter (open the filter, high-shelf boost); wider (more detune/voices, add Chorus+); darker/warmer for a pad-lead (lower the low-pass, longer attack); layer an octave-up saw for even more top.

**Descriptors it hits:** [wide](../descriptor-dictionary.md#wide), [lush](../descriptor-dictionary.md#lush), [bright](../descriptor-dictionary.md#bright) (see [descriptor-dictionary](../descriptor-dictionary.md)).
