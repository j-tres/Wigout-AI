# Warm Pad

**Use:** a soft, analog-leaning background pad — rounded and full in the low-mids, gentle on top, that sits under a track and fills space without drawing attention.

**Start from:** [Polysynth](../devices/polysynth.md) (two detuned saws) — see the guide. [Polymer](../devices/polymer.md) works equally well.

**Build:**
1. Two saw (or saw + triangle) oscillators, detuned a few cents against each other. The gentle beating gives width and life; the saws give body for the filter to round off.
2. Filter to low-pass, brought **down** so the brittle highs roll off — this, plus the slow envelope, is what makes it "warm" not "bright" (see [warm](../descriptor-dictionary.md#warm) in the dictionary). Modest resonance.
3. Amp envelope: slow attack (the pad swells in rather than plucking), high sustain, long release so notes overlap into a bed.
4. Slow LFO to filter Frequency or to detune for gentle, breathing movement (see [../../../coach/references/modulators.md](../../../coach/references/modulators.md)).
5. Chain: Saturator (very light drive for even harmonics = analog warmth) → EQ+ (small high-shelf cut above ~6 kHz if fizzy; a low-mid bump for body) → Reverb (medium hall, moderate mix, tail darkened so it sits behind). See [../fx-character.md](../fx-character.md).

**Parameter targets:** Detune subtle (a few cents). Filter low-pass ~30-50%, resonance low. Amp attack slow, sustain high, release long. Saturator drive very low. Reverb tail darkened, mix moderate.

**Variations:** warmer/darker (lower the low-pass further, saw → triangle — but watch [muddy](../descriptor-dictionary.md#muddy)); brighter (open the filter, drop the high-shelf cut); wider (add Chorus+ and more detune — see [lush-pad](lush-pad.md) for the full-width version).

**Descriptors it hits:** [warm](../descriptor-dictionary.md#warm), [lush](../descriptor-dictionary.md#lush) (see [descriptor-dictionary](../descriptor-dictionary.md)).
