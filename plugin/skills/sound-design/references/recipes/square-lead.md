# Square Lead

**Use:** the hollow, reedy, video-game/chiptune-adjacent lead — a pulse/square oscillator lead with a clarinet-like woody core, great for retro melodies and PWM-driven movement.

**Start from:** [Polysynth](../devices/polysynth.md) (square/pulse oscillator with a pulse-width control) — see the guide. Polymer with a pulse-capable slot works too.

**Build:**
1. Square or pulse oscillator. A 50% pulse (true square) is hollow with only odd harmonics — the reedy core. Narrower pulse widths thin out and get more nasal.
2. For movement, modulate the **pulse width** (PWM) with a slow LFO — a single pulse oscillator gains a chorus-like shimmer without a second oscillator (see [../devices/polysynth.md](../devices/polysynth.md) on pulse width, and [../../../coach/references/modulators.md](../../../coach/references/modulators.md)).
3. Filter to low-pass, opened mid-high so the reedy harmonics read; modest resonance for a vocal edge.
4. Amp envelope: fast attack, high sustain, short-to-medium release for a held lead; for a chiptune stab, shorten decay and drop sustain.
5. Chain: EQ+ (a small presence bump ~2-4 kHz helps it cut) → synced Delay+ for the classic retro echo → light Reverb. See [../fx-character.md](../fx-character.md).

**Parameter targets:** Pulse width near 50% for a full square, or offset for a thinner nasal tone; PWM LFO slow and shallow. Filter low-pass ~55-70%, resonance modest. Amp attack ~0%, sustain high.

**Variations:** fuller (widen pulse toward 50% — see [hollow](../descriptor-dictionary.md#hollow) if it feels too scooped); brighter (open the filter, add a detuned second oscillator); dual-osc detuned square for a thicker, wider lead.

**Descriptors it hits:** [hollow](../descriptor-dictionary.md#hollow), [bright](../descriptor-dictionary.md#bright) (see [descriptor-dictionary](../descriptor-dictionary.md)).
