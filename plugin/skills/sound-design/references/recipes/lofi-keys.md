# Lo-fi Keys

**Use:** the dusty, warbly, slightly-detuned keyboard of lo-fi hip-hop and chillhop — a mellow electric-piano or soft-synth key run through tape-style wobble, filtering, and grit so it sounds recorded to a worn cassette.

**Start from:** [FM-4](../devices/fm-4.md) for a Rhodes-style tine key (see [electric-piano](electric-piano.md) for the clean version), or [Sampler](../devices/sampler.md) with a piano/keys multisample — see the guides. The lo-fi character is mostly in the *processing*, so either source works.

**Build:**
1. Start with a mellow keys tone — a soft EP from FM-4 (modest modulation depth, gentle attack) or a filtered piano sample.
2. Take the top off: low-pass the filter down so it sounds dark and distant — lo-fi keys are never bright (see [dark](../descriptor-dictionary.md#dark)).
3. Add pitch instability: a slow, shallow LFO to oscillator/sample pitch for the tape warble/wow-and-flutter that defines the genre (see [../../../coach/references/modulators.md](../../../coach/references/modulators.md)). Keep it subtle — a few cents.
4. Amp envelope: soften the attack slightly and let notes ring a touch so it feels hazy, not tight.
5. Chain: Saturator (light drive for tape-style warmth and harmonics) → a bitcrush/downsample device for digital grime (browse Bitwig's bit-reduction family and **confirm the exact device name live** — see [../fx-character.md](../fx-character.md)) → EQ+ (roll off highs and a little sub; leave a warm low-mid) → short Reverb for room. Optionally add vinyl-crackle noise as a separate layer.

**Parameter targets:** Filter low-pass ~30-45% (dark). Pitch-wobble LFO slow, depth a few cents. Saturator drive low-moderate. Bitcrush subtle (grime, not destruction). EQ high-shelf cut, gentle high-pass. Amp attack slightly softened.

**Variations:** dustier (more bitcrush, add crackle, narrower bandwidth); warmer/cleaner (less crush, open the filter a little — see [warm](../descriptor-dictionary.md#warm)); wobblier (deeper/slower pitch LFO for a more broken-tape feel — watch it doesn't turn [muddy](../descriptor-dictionary.md#muddy)).

**Descriptors it hits:** [warm](../descriptor-dictionary.md#warm), [gritty](../descriptor-dictionary.md#gritty), [dark](../descriptor-dictionary.md#dark) (see [descriptor-dictionary](../descriptor-dictionary.md)).
